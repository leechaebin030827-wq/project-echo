# 월드 진입 이후 나레이션 녹음 목록

## 이번 녹음 범위

- 시작점: 인트로 영상 종료 후 월드 진입.
- 한국어: 월드 진입·기본 안내·이동·태평양 도착·귀환, **네바다와 하미나의 모든 오브젝트 호버 문구**, 춤 그룹 호버 문구.
- 영어: 네바다 월드에서 의식·춤·오브젝트를 선택한 뒤 나오는 대사.
- 핀란드어: 하미나 월드에서 의식·춤·오브젝트를 선택한 뒤 나오는 대사.
- 이번 목록에서 제외: 인트로 영상 내레이션, 인물 시작 질문 `당신은 누구예요?`, 인물 대화 A/B/C, 버튼·자료 카드·위치 타이틀, 오류 안내.
- 호버 문구는 두 월드 모두 한국어만 사용한다. 현지어 표의 한국어는 녹음 대사가 아니라 원문 확인용이다. 표의 행은 원본 자막의 문장·줄바꿈 순서를 따른다.
